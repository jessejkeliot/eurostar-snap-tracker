Extract train trip details into JSON with fields: origin, destination, outbound_date, end_date, inbound_date.

Origin/destination must be one of: Paris Gare du Nord, Amsterdam Centraal, Brussels, Lille Europe, Cologne Hbf, Rotterdam Centraal, London St Pancras.
Dates must be formatted as yyyy-mm-dd.
If no return date is given, omit inbound_date.
If user specifies a range of possible days for the outbound journey, put the end of range in end_date. If they don't specify a range for the outbound, omit end_date.
