# Conversion Strategy – Eurostar Snap WhatsApp Bot

## Overview

This document outlines the conversion-optimized funnel for the Eurostar Snap tracker bot.  
The goal is to maximize:

- Activation (user sees value quickly)
- Conversion (free → paid)
- Retention (ongoing subscription value)

---

# Core Principles

1. Show value immediately
2. Let users experience the product before paying
3. Avoid hard paywalls early
4. Use urgency + loss aversion to drive upgrades
5. Continuously reinforce savings

---

# Funnel Breakdown

## 1. Entry (First Message)

**Goal:** Instantly communicate value

**Message:**
```
👋 I find ultra-cheap Eurostar Snap tickets (often £30–£50).

Tell me your route (e.g. London → Paris) and I’ll alert you instantly.
```

---

## 2. Personalization

**Goal:** Get user commitment

**Message:**
```
Nice — I’ll track London ↔ Paris deals for you.

You’ll get your first 3 alerts free.
```

---

## 3. Instant Value Demonstration

**Goal:** Prove value immediately

**Message:**
```
🔥 Example deal:
London → Paris for £39
(Usually ~£120+)

I’ll send you deals like this as they drop.
```

---

## 4. Free Trial (Usage-Based)

- 3 free alerts per user

---

## 5. Alert Experience

**Free Users:**
- Receive alerts
- Optional delay (10–15 minutes)

**Paid Users:**
- Instant alerts
- Unlimited notifications

---

## 6. Soft Paywall

**Trigger:** After 3 alerts

**Message:**
```
🚨 Snap ticket found:
London → Paris £42 (normally £115)

You’ve used your free alerts 👀

Upgrade for:
⚡ Instant alerts
🔁 Unlimited deals

👉 £4.99/month
[Subscribe link]
```

---

## 7. Delay Mechanic

```
You’re seeing this 5 minutes later than premium users ⏱️
```

---

## 8. Payment Flow

- Stripe checkout link
- £2.49/month
- £24.99/year

---

## 9. Post-Purchase Experience

```
✅ You’re now on premium

You’ll get:
⚡ Instant alerts
🎯 Priority deals

Next deal could drop anytime 👀
```

---

## 10. Retention Messaging

```
🔥 £35 Paris deal just dropped
(you got this instantly)
```

```
You’ve saved £120+ already 💸
```

---

# Re-Engagement Strategy

```
Another cheap fare just dropped 👀

```

---

# Pricing Strategy

- Free: 3 alerts
- Paid: £4.99/month or £39/year

---

# Key Psychological Triggers

- FOMO
- Loss aversion
- Anchoring
- Speed advantage
- Savings reinforcement

---

# What NOT to Do

- No hard paywalls
- No upfront payment requirement
- Don’t delay first value

---

# Metrics to Track

- Route setup rate
- First alert rate
- Conversion rate
- Churn rate

---

# Summary

1. Hook with cheap fares
2. Personalize
3. Show value fast
4. Give 1–3 alerts
5. Soft paywall
6. Convert
7. Reinforce value
